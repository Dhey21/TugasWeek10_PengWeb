# TugasWeek10_Pengweb
 REST API data mahasiswa untuk Tugas Bab 10 (Perancangan dan Pemrograman Web).

## Deskripsi
Backend sederhana untuk mengelola data mahasiswa (nama, NIM, jurusan) yang dibangun dengan NestJS. Data disimpan permanen di database PostgreSQL melalui Prisma ORM, sehingga tetap ada setelah server di-restart.

Fitur:
- CRUD data mahasiswa (create, read, update, delete)
- Filter data berdasarkan jurusan
- Statistik jumlah mahasiswa (total dan per jurusan)
